# RG Rokometni trening

Osebno orodje za sestavljanje rokometnih treningov.

## Uporaba

Aplikacija je dostopna na: **https://uikreator.github.io/RG-rokometni-trening**

## Lokalna uporaba

Odpri `index.html` v brskalniku.

## Funkcionalnosti

- Vnos vaj s slikami (do 3), opisi, opremo
- 6 faz: ogrevalna igrica, tehnično ogrevanje, fizično ogrevanje, vaja, simulacija, igra
- Avtomatska sestava treninga (napad / obramba / oboje)
- Zamenjava posameznih vaj
- Zgodovina treningov + refleksija
- Avtomatski backup (po 10 spremembah ali 7 dneh)
- Ročni izvoz/uvoz za prenos med napravami
- Deluje offline (PWA)

## Backup

Podatki so shranjeni lokalno v brskalniku. Za prenos med napravami:
- **Izvoz** (gumb ⇱) → JSON datoteka
- **Uvoz** (gumb ⇲) na drugi napravi → izberi JSON datoteko
